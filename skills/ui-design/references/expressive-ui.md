# Expressive UI：母題語法與表現力等級

參考女神異聞錄 5、33 號遠征隊那類自由、風格化的 UI，整理成可以套到一般產品的方法。核心是兩件事：**母題**決定「長什麼樣」，**等級**決定「風格化到哪裡為止」。

互動版本：`examples/expressive-ui-lab.html`（12 母題 × L0–L4）。母題的完整契約在 `motif-library.md`，實作片段在 `expressive-recipes.md`，頁面層級的分配在 `composition-grammar.md`。

---

## 核心規則

> 外殼盡情表現，核心保持可讀。框可以歪，字不歪。

- 內文永遠 0°；display 標題最多約 ±12°，多行標題只轉一半角度
- 自由感來自**少數強規則反覆出現**（例如只准用 [-12, -6, 4, 9] 四個角度），不是到處隨機
- 每個風格化元素都要能說出它在材料世界裡是什麼（底板＝剪下的紙、按鈕＝朱印、標題＝門牌），說不出來就刪掉

## 母題語法（Motif Grammar）

先選一個「世界材料」，再從材料推導整套規則，而不是先選網格再塗顏色。每個母題用同一組欄位定義：

| 欄位 | 說明 | 例：預告信 |
|---|---|---|
| `world_material` | 世界材料 | 預告信、勒索信拼貼、龐克海報 |
| `mark` | 筆觸：cut / brush / ink / engrave / overprint / carve-stamp / draw / glyph / pixel / lead-came / light / survey | cut |
| `shapes` | 形狀語彙 | 鋸齒多邊形、爆炸星、斜切色帶、網點 |
| `angle_set` | 只准用的角度 | [-12, -6, 4, 9] |
| `palette_lock` | 鎖定的色彩，不再加別的顏色 | 訊號紅、墨黑、紙白 |
| `selection_metaphor` | 選取隱喻，整個風格的招牌時刻 | 鋸齒底板「啪」地貼到焦點項目，後面墊一層錯位色板 |
| `transition_verb` | 轉場動詞：slash / bloom / cut / flip / register / stamp / draw / boot / mosaic / assemble / spotlight / plot | slash：三條斜切色帶掃過 |
| `legibility_core` | 可讀核心，任何等級都不風格化 | 內文、表單、數字 |

選母題的順序：

1. **先從產品自己的世界找**：產品處理的實體物件是什麼？（地址→門牌、卡牌→評級卡盒、工程→製圖）這樣母題有理由，也不會撞款
2. 找不到才借用文化母題（遊戲、印刷、工藝、資訊技術），而且要研究它真正的特徵，不要只取表面符號
3. 用 `composition-grammar.md` 的相容性矩陣找版面語法

## 表現力等級 L0–L4

| 等級 | 名稱 | 風格化範圍 | 不動的核心 | 適用 |
|---|---|---|---|---|
| L0 | 點綴 | 區段標記、完成時的過場、清單清空時的空狀態 | KPI 數字、任務列、按鈕維持產品原樣 | SaaS、後台、金融、醫療等高信任產品 |
| L1 | 框架 | 眉標、標題、小標、區段分隔、引言 | 內文段落、作者與日期 | 部落格、文件站、商品頁、新聞稿 |
| L2 | 外殼 | 導覽與選取底板、按鈕、開關、對話框外框 | 表單欄位、說明文字、對話框內文 | 消費型 App、社群、會員中心 |
| L3 | 舞台 | 整個畫面的構圖、主視覺、標題字、選單 | 選項說明文字 | 遊戲選單、活動頁、產品發表、作品集首頁 |
| L4 | 表演 | 轉場編排、數字滾動、評等印章 | 最終數字：靜止時就完整可讀，動畫只是播放方式 | 結算、年度回顧、成就解鎖、onboarding 完成 |

- 等級是**按區域**給的，不是整個產品一個等級。分配規則（安靜區至少 3 個、L3 最多 2 個）見 `composition-grammar.md`
- L4 只出現在「事件」上（完成、結算、換場），不常駐
- 往上一級會包含下一級的處理；L1 的頁面不會有 L2 的按鈕樣式

## 無障礙規則

風格化 UI 最容易出事的地方，每一條都要檢查：

1. **對比**：可讀核心照 WCAG AA。風格化底板上的文字也一樣，反白、套印、網點都要量
2. **焦點**：每個母題都要有自己的 focus 樣式，而且能看見。`clip-path` 會把 outline 裁掉，改用 inset box-shadow
3. **拼貼字與逐字效果**：完整文字放在 `.vh`（visually hidden），逐字的 span 設 `aria-hidden="true"`
4. **選取不能只靠顏色**：底板、形狀、位置至少再用一種
5. **reduced-motion**：L4 的編排要有靜態版本，最終狀態要完整；持續動畫（游標閃爍、閃卡光澤）全部停掉
6. **旋轉**：只給 display 文字與底板；表單、內文、數字不旋轉
7. **觸控目標**：鋸齒或斜切的按鈕，可點擊範圍仍要 44×44 以上，不能被 clip-path 縮小
8. **語意**：裝飾件（圖框標題欄、套印標記、落款）設 `aria-hidden`；有資訊的裝飾（期號、圖號）要在可讀的地方也出現

## 風格化 UI 的 cliché

除了 `style-genome.md` 的通用 cliché 清單，風格化 UI 另外有這些（各 1 分）：

- 到處隨機旋轉，沒有角度集
- 所有標題都用拼貼字
- 到處 glitch 或掃描線
- 每個區域都是 L3，沒有安靜區
- 母題只出現在顏色上，筆觸、選取、轉場都是預設的
- 轉場一律淡入淡出，跟材料的動詞無關

## 階段 2 的預覽要求

使用風格化母題時，`preview-[功能].html` 除了元件之外，還要包含：

- 每個用到的等級各一個代表畫面
- **轉場分鏡**：母題的 transition_verb 實際播放一次，並附 reduced-motion 版本
- 選取隱喻的互動（滑鼠、鍵盤、觸控）
- 可讀核心的標示（實驗室的「標示可讀核心」開關就是這個用途）
